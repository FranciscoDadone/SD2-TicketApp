# TicketApp - Orders Service

## Sistemas Distribuidos II - 2026

Sistema de gestión de órdenes de tickets para eventos. Permite crear, consultar, actualizar y validar órdenes de compra de tickets.

### Ejecución local

```sh
./gradlew bootRun
```

El servicio estará disponible en: `http://localhost:8080`

### Documentación de la API

#### Swagger UI
